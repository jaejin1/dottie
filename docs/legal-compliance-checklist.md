## 1. 🔴 위치기반서비스사업 신고 (한국 — 가장 중요)

Dottie는 위치정보를 수집·이용·제공하는 서비스라 **위치정보법상 신고 대상**.

- **방송통신위원회에 "위치기반서비스사업자" 신고** 필요 (개인/법인 모두 가능)
  - 신고 사이트: 전파관리소 (위치정보사업 신고 시스템)
  - 처리 기간 보통 2~4주 — **가장 먼저 시작할 것**
  - 미신고 영업 시 형사처벌 조항 있음
- 신고 완료 후 **위치기반서비스 이용약관**에 신고번호 기재
- 참고: 친구와 위치 공유(room)까지 있으므로 "개인위치정보를 제3자에게 제공"에
  해당 — 약관에 제공 대상·목적 명시 + 제공 시마다 동의 근거 필요 (auto_share
  토글이 이 동의 UI 역할 — 약관에 그렇게 기술)

## 2. 🔴 필수 문서 4종 (웹 호스팅 필요)

앱은 이미 아래 URL로 연결되도록 구현됨 (설정 탭 → 앱 정보). **문서 작성 + 호스팅만 하면 됨.**

| 문서 | URL (앱에 연결됨) | 근거 |
|------|------|------|
| 서비스 이용약관 | `https://app.dottie.today/terms` | 전자상거래법·정보통신망법 |
| 개인정보처리방침 | `https://app.dottie.today/privacy` | 개인정보보호법 (필수), 양대 스토어 필수 |
| 위치기반서비스 이용약관 | `https://app.dottie.today/location-terms` | 위치정보법 |
| 오픈소스 라이선스 | 앱 내장 (`showLicensePage`) | 각 라이선스 의무 |

- 호스팅: BE가 `app.dottie.today`를 이미 서빙 중이므로 정적 HTML 3장 추가가 가장 간단
  (Go 서버에 static route — `/terms`, `/privacy`, `/location-terms`)
- 개인정보처리방침 필수 기재 사항 (개인정보보호법 30조):
  수집 항목(위치, 이메일/닉네임/프로필, 사진, 푸시토큰) / 수집 목적 /
  보유 기간 / 제3자 제공(room 멤버에게 위치 공유) / 처리 위탁
  (**Firebase(Google), Mapbox, Kakao, Fly.io, Cloudflare R2 — 국외이전 고지 필수**) /
  파기 절차 / 정보주체 권리 / 개인정보보호책임자 연락처
- 초안은 방통위 "위치기반서비스 이용약관 표준안" + 개인정보위 표준 개인정보처리방침을
  베이스로 작성 권장

## 3. 🟡 스토어 심사 요구사항

### App Store (Apple)
- [ ] App Privacy "영양성분표" 작성 — 위치(정밀), 사용자 콘텐츠(사진), 식별자, 연락처 정보
- [ ] 개인정보처리방침 URL 등록 (위 `/privacy`)
- [x] 계정 삭제 기능 (설정 → 회원 탈퇴 — 이미 구현됨, 5.1.1(v) 충족)
- [x] 위치 권한 문구 (Info.plist NSLocation* — 이미 있음. 심사 시 "왜 Always가 필요한가"
      리젝 가능성 → 자동 기록 기능 설명을 심사 노트에 첨부)
- [ ] 로그인: Apple 로그인 있음 (제3자 로그인 제공 시 Sign in with Apple 필수 — 충족)
- [ ] 카카오 로그인 버튼 디자인 가이드 (공식 심볼/문구 — 반영 완료)

### Google Play
- [ ] Data safety 폼 — 위치(정밀/백그라운드), 사진, 개인 식별 정보
- [ ] **백그라운드 위치 권한 선언 + 심사 영상** — `ACCESS_BACKGROUND_LOCATION` 사용 앱은
      Play Console에서 별도 declaration + 기능 시연 영상 요구. 자동 기록 기능이 근거.
      "포그라운드로 대체 불가한 이유"를 명확히 작성할 것 (자동 dot 기록)
- [ ] 개인정보처리방침 URL

## 4. 🔴 오픈소스/에셋 라이선스

### 앱 내 고지 (완료)
- 설정 → 앱 정보 → **오픈소스 라이선스** 메뉴 구현됨 — Flutter `showLicensePage`가
  모든 pub 패키지의 LICENSE를 자동 수집해 표시. pub 패키지는 이걸로 의무 충족.

### ⚠️ 별도 확인 필요한 것들

1. **LPC 캐릭터 스프라이트 (assets/character/)** — 가장 주의.
   Universal LPC Spritesheet 에셋은 **CC-BY-SA 3.0 / GPL 3.0** 라이선스로,
   **아티스트별 크레딧 표기 의무**가 있음. 제너레이터가 뽑아주는 CREDITS.csv를
   기반으로 앱 내(오픈소스 라이선스 페이지 or 별도 크레딧 화면)에 표기해야 함.
   CC-BY-SA는 2차 저작물 동일 라이선스 조건도 있으므로, 상용 배포 전에
   사용한 에셋들의 정확한 라이선스 조합 확인 필요.
   → `LicenseRegistry.addLicense()`로 Flutter 라이선스 페이지에 커스텀 항목 추가 가능.
2. **Mapbox** — 상용 SDK. 지도 위 Mapbox 로고·attribution(ⓘ) 제거 금지 (약관 위반).
   현재 표시 중 — 유지하면 됨.
3. **폰트** — GoogleFonts(NotoSansKr, Jua)는 OFL — LicensePage에 자동 포함됨.
4. **아이콘/이모지** — Material Icons(Apache 2.0) 자동 포함. 트위모지 등 별도
   이모지 에셋 쓰면 CC-BY 고지 필요 (현재 시스템 이모지라 해당 없음).
